روش اجرا
--------
۱) همه‌ی فایل‌ها را با همان ساختار پوشه‌ای روی هاست بگذار:
   /
   ├── index.html
   ├── sw.js
   ├── icon-192.png
   ├── icon-512.png

۳) نام فایل اصلی باید دقیقاً index.html باشد، چون سرویس‌ورکر برای حالت
   آفلاین به همان تکیه می‌کند.

تنظیمات اختیاری
---------------
در فایل index.html، ابتدای اسکریپت، شیء CFG را ببین:

  var CFG = {
    igUser: 'fitalirezaakbari',
    igUrl:  'https://instagram.com/fitalirezaakbari',
    visionUrl: '',            // ← آدرس سرویس تحلیل تصویر
    offApi: 'https://world.openfoodfacts.org',

    leadPhone: '989123456789',   // ← واتساپ خودت، بدون + و بدون صفر
    leadTg:    'arakbari73',     // ← آیدی تلگرام خودت بدون @
    leadSms:   '+989123456789',  // ← شماره پیامک خودت با +
    leadUrl:   '',               // ← آدرس سایت/اینستاگرام که در پیام درج می‌شود

    // ---- تنظیمات لایه‌ی سوپر اپ (همه اختیاری؛ خالی بمانند، اپ آفلاین کار می‌کند)
    apiUrl:       '',    // بک‌اند حساب/OTP و همگام‌سازی ابری
    cgmUrl:       '',    // سرویس خواندن خودکار قند خون (CGM)
    healthAggUrl: '',    // سرویس تجمیع سلامت (Health Connect / گجت‌ها)
    analyticsUrl: '',    // دریافت رویدادهای آماری ناشناس
    fcmKey:       '',    // کلید FCM برای پوش سرورمحور
    payUrl:       '',    // صفحه‌ی پرداخت (زرین‌پال/آیدی‌پی و...)
    adminPin:     '1234',// PIN ورود به پنل مدیریت محتوا
    feed:         null   // آیتم‌های فید محتوا در صفحه‌ی «شبکه»
  };

- اگر شماره‌ی واقعی‌ات با این نمونه‌ها فرق دارد، همین سه خط را عوض کن.
  با پر بودن این مقادیر، پیام‌ها مستقیم به خودت می‌رسد (بدون انتخاب مخاطب).
  اگر خالی بمانند، اپ همان پیام‌رسان را باز می‌کند و کاربر مخاطب را خودش
  انتخاب می‌کند.

- تحلیل عکس غذا و خواندن برچسب (OCR): تا وقتی visionUrl خالی باشد،
  این دو دکمه خودکار غیرفعال‌اند. آدرس سرویس را که گذاشتی، فعال می‌شوند.
  سرویس باید POST با بدنه‌ی JSON {mode:'food'|'label', image:'data:...'}
  را بپذیرد و {items:[{name,kcal,prot,carb,fat}]} برگرداند.

- جستجوی غذا و اسکن بارکد از Open Food Facts استفاده می‌کنند (به اینترنت
  نیاز دارند). بانک داخلی غذاها آفلاین کار می‌کند.

- برای خواندن «آب» سریع، دکمه‌ی شناور 💧 گوشه‌ی صفحه را بزن.
- در موبایل یک دکمه‌ی شناور ⚡ هم داری که مستقیم بخش «فست هوشمند» را باز می‌کند.

ظاهر و تم‌ها
------------
- حالت تاریک (شب) به‌طور کامل حذف شده؛ برنامه روشن و خواناست.
- دکمه 🎨 (بالا/منو): حالت نمایش ☀️ روشن / 🌈 شاد.
  «شاد» کل برنامه را رنگی و سرزنده می‌کند: پس‌زمینه‌ی گرادیانی،
  کارت‌های سفید پرشکوه، سرصفحه‌های رنگی و کارت‌های خانه با پالت شاد.
- دکمه‌ی سریع ☀️/🌈 در نوار بالا بین روشن و شاد جابه‌جا می‌کند
  (آیکن دکمه با تم فعلی عوض می‌شود).
- رنگ اصلی (زمرد، اقیانوس، بنفش، رز، غروب، سایبر، لیمویی، زرشکی، نیلی)
  جداگانه قابل انتخاب است و در حالت شاد هم کار می‌کند.
- پنل «فست هوشمند» طراحی تازه دارد: هیروی گرادیانی شمارش معکوس،
  کارت‌های پلن با نشان ساعت و تایم‌لاین رنگی فازها.

فرم «شروع با من» (جذب مخاطب)
-----------------------------
مسیر: منو ← 📝 فرم شروع با من  (یا دکمه‌ی روی داشبورد)

۱) کاربر هدفش، قد و وزن، سن، سطح فعالیت و الگوی فستینگش را وارد می‌کند
   (سه گام اول) و بعد اسم و شماره‌ی تماسش را می‌نویسد.
   شماره‌ی تماس اجباری است؛ تا وارد نشود، ارسال انجام نمی‌شود و پیام خطا
   زیر فرم نمایش داده می‌شود (اسم اختیاری است).
۲) بلافاصله سه دکمه‌ی ارسال را می‌بیند: واتساپ / تلگرام / پیامک.
   هیچ پیش‌نمایش یا گام اضافه‌ای وجود ندارد.
۳) با انتخاب هر کانال، متن فرم خودکار آماده و در کلیپ‌بورد کپی می‌شود و
   همان اپ باز می‌شود؛ کاربر فقط دکمه‌ی ارسال را می‌زند.
   شماره با ارقام فارسی هم قبول است و در پیام به شکل 09xxxxxxxxx درمی‌آید.

متن پیام شامل مشخصات کاربر + خلاصه‌ی برنامه‌ی پیشنهادی (کالری هدف،
BMR/TDEE، پلن فستینگ، ساعت و کالری وعده‌ها، آب و پروتئین) و تاریخ شمسی
است. این خلاصه پشت صحنه حساب می‌شود و به کاربر نمایش داده نمی‌شود؛
فقط در پیام ارسالی دیده می‌شود.

یادداشت: مرورگر اجازه نمی‌دهد سایتی خودش پیام بفرستد؛ به همین دلیل
«کپی خودکار + باز شدن اپ با متن آماده» بهترین رفتار ممکن است.

بخش «📚 آموزش»
--------------
۳۲ مقاله‌ی آموزشی دسته‌بندی‌شده در ۶ گروه: شروع سریع، فستینگ، تغذیه،
تمرین، خواب و ریکاوری، ذهن و انگیزه.

امکانات این بخش:
- جستجوی زنده روی عنوان و متن همه‌ی مقاله‌ها (ارقام فارسی و انگلیسی
  یکسان دیده می‌شوند).
- فیلتر دسته‌ها + چیپ «★ ذخیره‌شده» برای مقاله‌های نشان‌شده.
- نوار پیشرفت مطالعه و شمارنده‌ی «X از Y خوانده شد»؛ هر مقاله که باز شود
  خودش «✓ خوانده شد» می‌گیرد.
- کارت «🌟 پیشنهاد امروز» که هر روز مقاله‌ی متفاوتی را پیشنهاد می‌دهد.
- دکمه‌ی ⭐ ذخیره برای بعد و 📋 کپی متن مقاله (برای فرستادن به دیگران).
- جدول‌های مرجع (کالری خوراکی‌ها، ضریب فعالیت، پروتئین مواد غذایی،
  پلن‌های فستینگ) و کادرهای نکته‌ی کلیدی داخل مقاله‌ها.

همه‌ی این‌ها آفلاین کار می‌کنند و وضعیت مطالعه/ذخیره در همان مرورگر
ذخیره می‌شود.

لایه‌ی «سوپر اپ» (۷ بخش جدید)
------------------------------
تب ⚡ «فست هوشمند» در نوار پایین و گروه «⚡ سوپر اپ فستینگ» در منو:

۱) ⚡ موتور فستینگ حرفه‌ای
   - ۱۴ پلن آماده: ۱۲:۱۲، ۱۴:۱۰، ۱۶:۸، ۱۸:۶، ۲۰:۴، OMAD، ۵:۲،
     یک‌روزدرمیان، ۲۴/۳۶/۴۸ ساعته، رمضان، قضای روزه، هماهنگ با چرخه.
   - شروع هوشمند: «آخرین وعده‌ات کِی بود؟» + پیشنهاد پلن بر اساس
     تاریخچه‌ی موفقیت خودت؛ تایمر روی همان موتور فستینگ قبلی می‌نشیند.
   - تایم‌لاین ۹ مرحله‌ای فیزیولوژیک (هضم ← گذار ← چربی‌سوزی ← کتون ←
     اتوفاژی ← اتوفاژی عمیق ← فست بلند ← ۳۶+ ← ۴۸+).
   - چک‌این انرژی/سرگیجه/سردرد + هشدارهای ایمنی خودکار (۳۶+ ساعت با
     علائم = توصیه به شکستن فست).
   - پروتکل ریفیدینگ (Refeeding) بر اساس طول فست، در ۴ سطح.
   - آمار پیشرفته: ساعت کل، طولانی‌ترین، میانگین، پایبندی ٪، نمودار
     هفته‌به‌هفته و تقویم ۳۰ روزه.
   - مربی هوشمند: تحلیل وزن، پایبندی، خواب، پروتئین، آب، فعالیت و علائم.
   - اعلان نقاط عطف ۱۲/۱۶/۱۸/۲۴/۳۶/۴۸ ساعت.
   - غربالگری ایمنی ۷ سؤالی: با جواب «بله»، پلن‌های ۲۴ ساعت و بالاتر
     قفل می‌شوند. (فست خشک عمداً وجود ندارد.)

۲) 🧠 سلامت و بیومتریک
   - امتیاز بازیابی روزانه ۰ تا ۱۰۰ (خواب، فعالیت، آب، پروتئین،
     فستینگ، استریک) با گیج رنگی و توصیه.
   - ثبت کتون و قند خون + نمودار روند + برچسب «فست چند ساعته بودی».
   - ثبت فشار، ضربان و دما + هشدار مقادیر غیرطبیعی.
   - عکس‌های پیشرفت با ذخیره‌سازی IndexedDB (localStorage جا نمی‌شد)،
     مقایسه‌ی خودکار «اولین و آخرین عکس» + تغییر وزن.
   - خروجی سلامت به JSON و CSV (برای Apple Health / Health Connect /
     اکسل) و ورود دوباره‌ی داده.
   - اتصال CGM و گجت‌ها از طریق cgmUrl / healthAggUrl.

۳) 🧩 تغذیه‌ی هوشمند
   - پلن‌ساز غذایی ۷ روزه بر پایه‌ی کالری و پروتئین هدف، تعداد وعده و
     پنجره‌ی خوردن؛ ۲۹ وعده‌ی ایرانی با فیلترهای گیاهی/بدون لبنیات/
     کم‌کربوهیدرات/اقتصادی/بدون گوشت قرمز و مقیاس‌گذاری پرس.
   - لیست خرید هفتگی خودکار با تیک‌زدن و شمارش وعده.
   - چک‌لیست ریزمغذی و الکترولیت روزانه.
   - ثبت سریع غذا با صدا (fa-IR) + ۴ برچسب دستور پخت (پروتئین بالا،
     کم‌کالری و...) با ثبت یک‌کلیکی وعده.
   - یادآورهای پنجره‌ی خوردن، پروتئین و آب.

۴) 👥 شبکه، دوستان و مربی
   - کد دوستی: آمار خلاصه (امتیاز، فستینگ، وزن، استریک) در یک کد؛
     جدول رتبه‌بندی دوستان با نوار امتیاز.
   - چالش‌های گروهی و «فست گروهی» با کد دعوت و نوار پیشرفت اعضا.
   - پنل مربی: سرنخ‌های فرم «شروع با من» خودکار اینجا می‌آید؛ تماس
     واتساپ/تلگرام، کپی متن اصلی، یادداشت، علامت «تماس گرفتم»،
     افزودن دستی شاگرد.
   - حالت سازمان/باشگاه (B2B) با کد سازمان.
   - فید محتوا + کارت اشتراک‌گذاری تصویری (کارنامه PNG).

۵) ☁️ حساب، اشتراک، پنل و امنیت
   - حساب و ورود با کد یک‌بارمصرف: اگر apiUrl خالی باشد در «حالت محلی»
     کد نمایش داده می‌شود (بدون ادعای پیامک واقعی) و اگر apiUrl ست شود،
     به سرور وصل می‌شود.
   - همگام‌سازی: با بک‌اند، ابری؛ بدون بک‌اند، «کد انتقال داده» برای
     جابه‌جایی بین دستگاه‌ها.
   - اشتراک رایگان/Pro/سازمان + کد فعال‌سازی (تولید کد در پنل مدیریت).
   - اعلان‌ها: اجازه، تست، یادآور آب/خواب/گزارش هفتگی + قلاب FCM.
   - پنل مدیریت با PIN (پیش‌فرض 1234): ویرایش قیمت‌ها، مقالات آموزش،

   - امنیت: قفل اپ با PIN، رضایت‌نامه‌ی سلامت، حذف کامل داده‌ها.
   - تحلیل رفتار و گزارش خطا (آفلاین، قابل کپی).

۶) ♿ تجربه‌ی کاربری و دسترس‌پذیری
   - آزمون راه‌اندازی ۵ سؤالی: پلن + کالری + پروتئین + گام‌های شروع.

فاز ۱۶ — 🌸 چرخه و انرژی (نسخه v12) — ویژه بانوان
--------------------------------------------------
یک بخش جدید هوشمند برای هماهنگی فستینگ، آب، تمرین، خواب و تغذیه با
چرخه‌ی ماهانه — پیش‌فرض مخفی و کاملاً اختیاری.

فعال‌سازی (۱۰ ثانیه):
- «settings ☰ منو ← تنظیمات و شخصی‌سازی» ← کارت 🌸 ← «فعال کن»
- بعد از فعال‌سازی: در منو گروه «🔥 سلامت و تناسب اندام» ← 🌸 چرخه و انرژی
  + یک کاشی 🌸 روی داشبورد هم ظاهر می‌شود

داخل بخش چی هست؟
- 🩸 ثبت شروع دوره (امروز / دیروز / ۲ و ۳ روز پیش)
- حلقه‌ی «روز X از میانگین Y» + نام فاز (قاعده‌سازی، فاز سازنده،
  روزهای اوج، پیش‌دوره)
- توصیه‌ی هر فاز برای ۵ چیز: فستینگ، آب و ریزمغذی، تمرین، خواب، تغذیه
- 🔮 پیش‌بینی تقریبی ۳ دوره بعد + پنجره باروری (±۲ روز)
- 🩹 علائم امروز (چیپ‌ها): هم اینجا ذخیره می‌شوند، هم خودکار در
  «دفترچه خاطرات» همان روز می‌نشینند + ۱ امتیاز هر ثبت
- 📆 سوابق دوره‌ها (حذف‌پذیر) و محاسبه‌ی میانگین چرخه از ثبت‌های واقعی
- پیوند مستقیم به دوره‌ی آموزشی «فستینگ و چرخه‌ی زنان»
- یادآور هوشمند: وقتی روزهای دوره یا پیش‌دوره‌ای، بنر بالای صفحه
  پیام مخصوص همان فاز می‌دهد (روزی یک بار، نه بیشتر)

فاز ۱۵.۱ — ایمنی داده (نسخه v11) — مهم‌ترین ویژگی برای کاربرهای قدیمی
----------------------------------------------------------------------
چه چیزی حل شد؟ ریسک شماره‌یک: «پاک شدن حافظه مرورگر = از دست رفتن
ماه‌ها ثبت وزن و فستینگ». حالا سه لایه:
۱) آینهٔ امن IndexedDB:
   - همهٔ داده‌ها به‌محض ذخیره، آینه‌شان در «حافظهٔ امن» مرورگر
     (IndexedDB — دیتابیس fitaData) هم می‌نشیند؛ این حافظه از اخراج
     خودکار قابل‌تخریب‌تر است و در «پاک شدن کوکی‌های قدیمی» جان می‌آورد
   - اگر روزی localStorage خالی/اکراج شود، اپ خودکار داده‌ها را از
     آینه برمی‌گرداند («♻️ حافظه از نسخهٔ امن بازگشت») و هر دستگاه
     حداکثر هر ۳۰ دقیقه یک‌بار بازمی‌سازد تا پاک‌سازی عمدی هم احترام داشته باشد
۲) حافظهٔ پایدار:
   - اپ در بوت navigator.storage.persist() درخواست می‌کند (در PWAِ
     نصب‌شده معمولاً بلافاصله قبول می‌شود) تا مرورگر اجازهٔ اخراج
     نداشته باشد
   - وضعیت حافظه + دکمهٔ درخواست در پنل «☁️ ► 🛡️ سلامت حافظه»
۳) یادآور پشتیبان:
   - اگر بیش از ۲۱ روز از آخرین فایل پشتیبان گذشته باشد (و دیتای واقعی
     داری)، بنر بالای صفحه می‌آید: «نگهبان مهم … پشتیبان فوری بگیر»
   - بستنش فقط ۳ روز سکوت می‌کند، بعد دوباره یادت می‌آورد
   - آخرین زمان‌های پشتیبان/بازیابی ثبت می‌شود تا شمارش روزها دقیق باشد
+ ابزار «🗑️ پاک‌سازی کامل از نو» در همان کارت — پاک‌سازی قطعی داده
  در هر دو حافظه برای شروع از صفر (چون تا حالا راه رسمی این نبود)

فاز ۱۴ — بازی و انگیزه (نسخه v8)
---------------------------------
کجا پیدایش کنی؟ سه راه:
۱) منوی ☰ (کشوی سمت راست) ← گروه «🏆 انگیزه و چالش» ← «🎮 بازی و انگیزه»
۲) کاشی «🎮 بازی و انگیزه» روی همان داشبورد اول
۳) پنل «🏆 چالش‌ها» ← دکمه‌ی پایین کارت

پنل جدید «🎮 بازی و انگیزه» همه‌ی این‌ها را یکجا دارد:

- 🏁 چالش ۲۱ روزه فستینگ: هر روزِ فعال (فست کامل یا ثبت وعده + فعالیت)
  یک خانه روشن می‌شود؛ با ۱۵ روزِ موفق، «گواهی چالش» تصویری ساخته و دانلود می‌شود.
- 🌱 درخت عادت: با پایداری روزانه از دانه تا شکوفه رشد می‌کند (و نمی‌میرد).
- 🎡 چرخ شانس هفتگی: برای کاربرانِ فعال، هفته‌ای یک چرخش — جایزه‌ی امتیاز
  یا ۳ روز Pro.
- ⚔️ دوئل فست: کد دوئل بساز، کد دوستت را وارد کن؛ برنده‌ی ۷ روزِ اخیر اعلام می‌شود.
- 📊 گزارش هفته: کارت تصویری «هفته‌ی تو» با میله‌های فست و آمار — قابل اشتراک‌گذاری.
- 🎧 درس صوتی روزانه: نکته‌ی روز با صدای فارسی در خودِ پنل.
- 🎁 کد هدیه Pro سه‌روزه و کد معرفی برای دوستان.

جاهای دیگر:
- 📣 نوار هوشمند بالای صفحه: بر اساس وضعیت فست، آب، ثبت وعده و کالری مانده
  پیام‌های به‌موقع می‌دهد (با دکمه‌ی بستن، ۴۵ دقیقه آرام می‌ماند).
- 🔍 جستجوی سریع سراسری: دکمه‌ی ذره‌بین بالای صفحه — غذا، دستور پخت، درس،
  مقاله و پنل‌ها را یکجا پیدا و باز می‌کند.
- 🧊 حالت تمرکز: در «⚡ فست هوشمند» هنگام فستِ فعال، دکمه‌ی «تمرکز» صفحه را به
  یک شمارش‌گر بزرگ و آرام تبدیل می‌کند (با افزودن لیوان آب و خروج).
- 🤖 پیشنهاد وعده بعدی: بالای پنل تغذیه، بر اساس کالریِ باقی‌مانده امروز.
- 🏅 ۹ مدال تازه: فست ۴۸ ساعته، استریک ۱۴ روزه، ۱۰۰ لیوان آب، ۲۰۰ وعده،
  درخت شکوفه، اولین دوئل، اولین چرخ، چالش ۲۱ روزه و… — با پاپ‌آپ جشن.
- 📈 پیش‌بینی وزن با روند واقعی: در پنل محاسبه، بر اساس وزن‌کشی‌های اخیر،
  وزن تقریبی ۳۰ روز بعد را نشان می‌دهد.
- 🎯 هدف هوشمند: پیشنهاد کالریِ بروزشده با ورزش دیروز و فست امروز (زیر «کالری امروز»).
- 🍳 فیلترهای دستور پخت: «⚡ زیر ۱۵ دقیقه» و «🍲 یک قابلمه» + ۷ دستور تازه.
- 🎓 دوره‌ی ششم: «پنجره خوردن و پروتئین» با آزمون و مدرک.
- 💾 پشتیبان هوشمند: هفته‌ای یک بار، خودکار فایل پشتیبان را می‌سازد.
- 🔤 اندازه متن: در «🎨 ظاهر» — عادی / درشت / بزرگ‌تر با ذخیره.
- 🗑 تم تاریک به‌کلی حذف شده است و فقط «☀️ روشن» و «🌈 شاد» باقی مانده‌اند.
